## Latest project: Keep Safe

**[Keep Safe](https://github.com/Maseeek/keep-safe)** lets you sign in to websites for your AI coding agents from your phone. When an agent reaches a login page, you get a notification, see the agent's real browser on your phone, type the sign-in yourself and hand the browser back. The agent never sees your password, and cookies stay on your computer.

It is a TypeScript monorepo with a Playwright browser bridge, a Model Context Protocol server that agents call, and a React PWA for the phone. [Try it](https://keep-safe-eight.vercel.app).
